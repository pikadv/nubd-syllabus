# NUBD Syllabus

A searchable website for the collected National University Bangladesh syllabus catalogue.

## Browse

The site lets visitors filter by degree type, department, academic year, and syllabus version, then search course titles and codes. The complete source data is available in [syllabus.json](./syllabus.json) and through the site's **Download full JSON** link.

## Data notes

The website presents the records exactly as collected in the catalogue. Some course lists were transcribed from reference pages and are not independently verified against official National University PDFs. Each syllabus card shows its recorded source and verification note where available.

## Publish with GitHub Pages

The repository includes a GitHub Actions workflow that deploys the static website from the `main` branch. In repository settings, GitHub Pages should use **GitHub Actions** as its build and deployment source.

The expected site URL is https://pikadv.github.io/nubd-syllabus/.
